Countersign logo

A terminal prompt, waiting. Countersign lives in the pipeline: before code that moves money can go live, it has to get past this prompt.

The idea

The $ is what every terminal shows before a command, and it hints at what Countersign protects: money.

The green cursor _ is waiting for the next step: the check, then the second signature.

The look is a dark terminal with a green cursor. The name is lowercase in IBM Plex Mono, like code.
